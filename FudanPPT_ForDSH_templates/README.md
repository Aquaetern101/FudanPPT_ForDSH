## 怎么用

任意目录都行，指给插件：

```bash
export DPPT_TEMPLATE_DIR=<本目录路径>
```

`assets/templates.json` 里登记的是文件名，因此这些文件必须**保持原文件名**；想改名或放别处，把 `templates.json` 里的 `file` 改成绝对路径即可。
